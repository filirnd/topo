Linux · Flatpak · Tapo Cloud

See your camera directly from your desktop.

Topo is a standalone Linux desktop app for viewing and controlling multiple Tapo cameras from one clean window. It uses the Tapo cloud relay, so there is no RTSP setup, port forwarding, VPN, or direct access to your home network.

Install with Flatpak View source on GitHub
Experimental software. Topo is an independent third-party project and uses undocumented Tapo cloud endpoints. It is not affiliated with or endorsed by TP-Link or Tapo.
Quick install

Install on Linux

Make sure Flatpak is installed, then run this command. It adds the Topo repository and keeps the app updateable.

flatpak install --user https://filirnd.github.io/topo/io.github.filirnd.topo.flatpakref

Launch it from your desktop menu or with:

flatpak run io.github.filirnd.topo

Prefer a graphical installation?

  1. Click Download .flatpakref below.
  2. Open the downloaded file with GNOME Software.
  3. Confirm the installation. The Topo repository is added automatically, so future updates appear through Flatpak.

What you get

A focused desktop view for your Tapo cameras.

Log in with your Tapo account, complete MFA when requested, and keep your cameras together in a native Linux window.

▦

Multi-camera live view

See multiple cloud camera streams in the same responsive dashboard, with per-camera loading, error, and retry states.

◉

Privacy controls

Enable or disable privacy mode for each camera and immediately reconnect its media relay after a state change.

↕

Pan and tilt

Move compatible cameras from a compact control panel with selectable movement steps.

⛶

Fullscreen viewing

Open any camera fullscreen with a button or double-click, while keeping controls in a separate drawer.

⌁

MFA and sessions

Sign in with Tapo app or email verification, reuse a saved session, and log out when you want a fresh login.

▣

Simple distribution

Install through this signed Flatpak repository hosted on GitHub Pages and receive updates through Flatpak.

Compatibility

Tested camera

Tapo C200 is currently the tested model.

  • Live cloud video: supported
  • Privacy mode: supported
  • Pan and tilt: supported

Have another model? Share your results and include the model and firmware version. Never include credentials, session tokens, or private footage.
